# 图片使用说明

## 文件夹结构

```
public/
  images/
    dishes/          # 菜品图片
    categories/      # 分类图片
    icons/          # 图标文件
```

## 正确的图片路径使用方法

### 1. 静态引用（推荐）
将图片放在 `public/images/dishes/` 文件夹中，然后在代码中使用：

```javascript
// 例如：public/images/dishes/红烧排骨.jpg
image: "/images/dishes/红烧排骨.jpg"
```

### 2. 动态导入
```javascript
import 红烧排骨 from '/public/images/dishes/红烧排骨.jpg'
// 然后使用: image: 红烧排骨
```

## 图片命名建议

1. 使用英文文件名（避免中文字符在某些服务器上的问题）
2. 使用小写字母和连字符
3. 例如：`hong-shao-pai-gu.jpg` 代替 `红烧排骨.jpg`

## 支持的图片格式

- `.jpg`, `.jpeg`
- `.png` 
- `.webp`
- `.svg`

## 注意事项

- 图片文件必须放在 `public` 文件夹内
- 路径始终以 `/` 开头（表示从网站根目录开始）
- Next.js 会自动优化 `public` 文件夹中的图片
